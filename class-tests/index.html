Natural Language Processing

Class tests

CSE 4811 / DS 4213, Fall 2026

There are four class tests, 20 marks in all. Each test is written on paper, in class, in 25 minutes.

Class Test 1

Topics

  1. Text as vectors: tokens, bag of words, TF-IDF and cosine similarity.
  2. Probabilities and loss: naive Bayes, softmax, the negative log-likelihood, cross-entropy, and training and validation sets.
  3. n-gram models: perplexity, add-one smoothing and backoff.
  4. The neural language model of Bengio et al. (2003), without the gradient algebra.
  5. Word2vec: skip-gram with negative sampling only.

Questions

Each question gives four statements, A to D. Write the set of the false statements, which may be empty or may hold all four, and correct each false statement by stating the right fact.

Practice

The practice problems are 25 questions in the format of the test. The slides explain the answer to each statement of 30 questions: 20 of the practice problems and 10 more on word2vec. Try the questions before you open the slides.
